Process overview

Football Data Pipeline

From the Sportmonks API to a browsable HTML dashboard

  1. 01

    Design the schema

    Designed a PostgreSQL schema based on the data available from the Sportmonks API endpoints.

  2. 02

    Create the database

    Created a PostgreSQL database named football.

  3. 03

    Load the data

    Wrote a Python script to load data league by league into the database via API requests.

  4. 04

    Validate

    Checked data integrity and normalisation with SQL queries.

  5. 05

    Analyse

    Wrote Python scripts to analyse the data from specific angles.

  6. 06

    Build the dashboard

    Used Claude to help extend the scripts so their output renders as an HTML dashboard.

  7. 07

    Combine

    Used Claude to concatenate everything into a single browsable file.
